# 길쪽지 기획서 (작품 소개)

> 공모전 접수양식 「02 앱 프로젝트 소개 / 심사 자료」의 내용을 옮긴 문서입니다. 참가자 정보·서명 페이지는 저장소에 올리지 않습니다.

## 1. 앱 한 줄 소개
**가족이 폰으로 남긴 음성 쪽지를, 차가 ‘그 장소’에 다가가거나 ‘그 사람’이 함께 탔을 때 알아보고, 안전한 순간에 운전자에게 들려주는 Pleos Connect 음성 쪽지 앱**

## 2. 기획 배경

#### ① 운전 중에는 가족의 마음을 받을 방법이 없다
- 운전 중에는 메시지를 확인할 수 없고(도로교통법상 주행 중 화면 조작 금지), 통화는 두 사람이 동시에 시간을 내야 합니다. 출퇴근길, 귀성길처럼 가족이 가장 걱정하는 시간에 오히려 연락이 끊깁니다.

#### ② 말은 ‘그 자리’에서 들어야 힘이 있다
- “빵 사 와 줘”는 아침에 받은 카톡보다 **빵집 앞을 지날 때** 들어야 의미가 있습니다. “여기 합류 구간은 미리 2차선으로”는 **그 구간에 들어서기 직전**에, “오늘 소풍 재밌게 놀아”는 **아이가 차에 탔을 때** 필요합니다.
- 그러나 기존 메신저와 전화는 모두 ‘보낸 시각’을 기준으로 전달됩니다. 장소와 상황을 기준으로 마음을 전하는 수단은 없습니다.

#### ③ 장소와 상황을 아는 기기는 차뿐이다
- 운전 중인 스마트폰은 꺼내 볼 수 없고, 차가 어느 방향으로 달리는지, 다음 회전까지 몇 m 남았는지, 뒷좌석에 누가 앉았는지 알 수 없습니다. 차는 이 모든 것을 압니다.
- 길쪽지는 이 차량 데이터를 ‘쪽지를 여는 열쇠’로 사용해, 이동 시간을 가족과 연결된 시간으로 바꿉니다.

## 3. 앱 주요 기능 및 차량 특화 요소

#### 핵심 기능

| 기능 | 내용 | 해결하는 문제 |
|---|---|---|
| ① 장소 쪽지 | 가족이 폰 지도에서 장소를 고르고 녹음 → 차가 그 장소에 다가가면 자동 재생 | “그곳을 지날 때” 꼭 필요한 말 전달 |
| ② 동승자 쪽지 | 좌석 착석 정보로 “아이가 뒷좌석에 탔을 때만”, “혼자일 때만” 열리는 쪽지 | 차 안의 함께하는 시간을 특별하게 |
| ③ 들었어요 · 답장 | 재생 즉시 보낸 사람 폰에 “들었어요” 표시, 정차 중 음성으로 답장 | 한 번 보내고 끝이 아닌 대화의 고리 |
| ④ 놓친 쪽지함 | 안전 때문에 보류되었거나 놓친 쪽지는 정차(P) 시 모아서 다시 듣기 | 안전과 전달률을 함께 확보 |
| ⑤ 쪽지 코스 (나만의 내비) | 경로를 따라 여러 쪽지를 이어 하나의 코스로 저장. 코스를 켜면 내비 안내 사이사이 가족의 목소리가 길을 알려줌 | 내비가 모르는 “우리 가족만 아는 길 정보” 전달 |

#### 차량 특화 요소
- **차가 재생 순간을 고른다**: 운전자는 아무것도 누르지 않습니다. 위치·진행 방향·속도로 쪽지 장소 도달을 판단하고, 다음 회전 안내가 가까우면 재생을 미뤄 직진 구간에서 들려줍니다.
- **차만 아는 열쇠**: 진행 방향, 다음 회전까지의 거리, 기어(주행·정차), 좌석 착석은 스마트폰이 알 수 없는 정보로, 길쪽지는 차 안에서만 성립하는 경험입니다.
- **주행 중 화면 조작 0**: 주행 중에는 음성으로만 동작하고, 목록·다시 듣기·답장은 정차 시에만 열립니다. 내비 안내 음성과 겹치지 않도록 오디오 포커스를 관리합니다.
- **가족은 앱 설치 없이**: 차 화면의 QR을 한 번 찍으면 폰 웹페이지에서 바로 녹음할 수 있어, 조부모·아이도 쉽게 참여합니다. 연결은 한 번만 하면 계속 유지됩니다.

## 4. 주요 사용 시나리오

#### 기본 흐름
**연결**(차 화면 QR을 폰으로 1회 스캔) → **남기기**(폰 웹에서 장소 또는 함께 탈 사람을 선택해 녹음, 여러 쪽지를 코스로 묶기 가능) → **전달**(서버가 차량으로 전송, 차가 미리 내려받음) → **재생**(조건 충족 + 안전한 타이밍에 자동 재생) → **확인**(보낸 사람 폰에 “들었어요”, 정차 중 답장)

#### 시나리오 1. 퇴근길의 아빠 (장소 쪽지)
- 점심시간, 엄마가 폰 지도에서 아빠 회사 앞 빵집을 찍고 “오늘 딸 생일이니까 크림빵 하나 사 와 줘”라고 녹음합니다.
- 저녁 퇴근길, 아빠의 차가 빵집 300m 앞 직진 구간에 들어서자 “엄마의 쪽지가 도착했어요” 안내 후 엄마 목소리가 재생됩니다. 엄마 폰에는 “아빠가 18:42에 들었어요”가 표시됩니다.

#### 시나리오 2. 아침 등원길 (동승자 쪽지)
- 출장 중인 엄마가 “아이가 뒷좌석에 탔을 때” 조건으로 “우리 OO, 오늘 소풍 재밌게 놀아!”를 남깁니다. 아빠와 아이가 함께 탄 등원길에 쪽지가 열려 둘이 같이 듣습니다.

#### 시나리오 3. 초보 운전 딸을 위한 아빠의 내비게이션 (쪽지 코스)
- 딸이 처음으로 차를 몰고 출근하기 전날 밤, 아빠가 폰 지도에서 딸의 출근 경로를 따라가며 쪽지를 하나씩 남기고 「첫 출근길」 코스로 묶습니다.
- “여기 합류 구간은 미리 2차선으로 가 있어”, “이 내리막엔 단속 카메라가 있어, 천천히”, “회사 주차장 입구는 건물 뒤쪽이야”, 그리고 도착 지점에서 “첫 출근 축하해, 잘하고 와”.
- 다음 날 아침 딸이 코스를 켜면, 일반 내비 안내는 그대로 두고 그 사이사이 아빠의 목소리가 해당 지점에서 길을 알려줍니다. 회전 안내와 겹치지 않도록 NaviHelper로 타이밍을 조정합니다.
- 길쪽지는 내비를 대체하지 않고, 내비 위에 **우리 가족만 아는 길 정보를 얹는 나만의 내비게이션**이 됩니다. 같은 방식으로 할머니 댁 가는 길, 아이 학원 픽업 길처럼 가족의 길을 코스로 만들어 두고 계속 다시 쓸 수 있습니다.

## 5. 개발 계획

#### 시스템 구성

| 구성 | 기술 | 역할 |
|---|---|---|
| 차량 앱 | Kotlin, Jetpack Compose, Pleos Connect (minSdk 28) | 쪽지 수신·저장, 위치/차량 상황 판단, 안전 타이밍 재생, QR 표시 |
| 가족 웹(폰) | HTML/JS, MediaRecorder, 지도 JS API | QR 연결, 지도에서 장소 선택, 조건 선택, 녹음·업로드, 들었어요 확인 |
| 서버 | Java 17, Spring Boot, Spring Data JPA, H2 → MySQL | 일회용 연결 코드 발급, 가족-차량 연결, 쪽지·음성 파일 보관 및 전달, 재생 기록 |

#### Pleos SDK / API 사용 계획

| SDK | 사용 내용 | 권한 |
|---|---|---|
| FusedLocation | 현재 위치·진행 방향을 받아 쪽지 좌표와의 거리 계산(차량 내 지오펜스). 반경은 속도에 비례해 조정, 반대 방향 통과 시 미재생 | FUSED_LOCATION |
| NaviHelper | 다음 회전(TBT)까지 거리로 재생 보류/재개 판단, 목적지 정보로 도착 쪽지 처리. (확장) 쪽지 장소를 경유지로 추가 | NAVI_ROUTE |
| Vehicle | 기어(P/D)로 주행·정차 구분, 방향지시등 작동 시 재생 보류, 좌석 착석 정보로 동승자 쪽지 조건 판정 | CAR_DRIVE, CAR_LIGHTS, CAR_SEATS 등 |
| TextToSpeech | “엄마의 쪽지가 도착했어요” 등 재생 전 안내 멘트 | TTS_SERVICE |
| SpeechToText | (2차) 정차 중 “다시 들려줘”, 음성 답장 명령 | STT_SERVICE |
- 외부 API: 지도 JS API(가족 웹의 장소 선택).
- SDK 제공 범위는 Pleos Playground에서 확인 후 확정하며, 미제공 항목은 Android 표준 API(LocationManager, Android TTS) 또는 외부 API로 대체합니다.

#### 핵심 구현 포인트
- **차량 내 판단**: 쪽지와 음성 파일을 미리 내려받아 차 안에서 거리·조건을 계산합니다. 터널·산간 등 통신 단절 구간에서도 재생되며, 차량의 실시간 위치를 서버에 저장하지 않습니다.
- **안전 설계**: CarUxRestrictions 준수, 주행 중 화면 조작 없음, 내비 음성과 겹치지 않도록 오디오 포커스 관리, 포그라운드 서비스로 다른 앱 사용 중에도 동작.
- **연결 보안**: QR에는 3분 후 만료되는 일회용 코드만 담고, 연결 후에는 토큰으로 인증합니다. 차량 화면에서 연결된 가족을 관리·해제할 수 있습니다.
- **검증**: Pleos Connect Emulator와 Virtual Console로 주행 경로, 기어, 좌석 상태를 시뮬레이션해 시연합니다.

## 6. 기대효과 및 발전 가능성

#### 사용자 가치
- **운전자**: 화면을 보지 않고도 가족의 목소리를 가장 필요한 순간에 듣습니다. 출퇴근·장거리 이동의 외로움을 덜고, 길 위의 주의 사항 같은 실용 정보도 그 자리에서 전달됩니다.
- **가족**: “잘 가고 있을까” 하는 걱정을 정확한 타이밍의 한마디로 전하고, “들었어요”로 안심합니다.
- **현대차그룹**: 차 안에서만 가능한 감성 경험으로 오너의 애착과 재방문 이유를 만들고, Pleos 앱마켓의 차별화 콘텐츠가 됩니다.

#### 타깃 고객
- **1차**: 자녀를 둔 30~40대 가족 차주. 출퇴근·등하원·주말 가족 이동이 많고 배우자·자녀와의 소통 수요가 큼.
- **2차**: 장거리 운전자, 부모님 차량(자녀가 부모님의 운전을 걱정하는 가족), 연인·친구.

#### 예상 MAU 및 Retention (가정 기반 추정)
- MAU = Pleos Connect 탑재 차량 수 × 앱 설치율 × 월 활성 비율. 예) 탑재 차량 100만 대 × 설치율 5% × 월 활성 60% ≈ **MAU 3만**.
- Retention 확보 장치: 매일 같은 길에서 반복되는 **반복 쪽지**와 계속 다시 쓰는 **쪽지 코스**, 가족이 없어도 쓰는 **나에게 남기는 쪽지**(“마트 근처 지나면 우유 사기”), **들었어요·답장**으로 이어지는 대화 고리. 목표 지표는 D30 Retention 40%, 활성 가족당 주 2건 이상 쪽지입니다.
- 운영 비용: 30초 음성 1건은 약 240KB 수준으로 가볍고, 위치 판단을 차량에서 처리해 서버 부하가 낮습니다.

#### 향후 서비스 확대

| 단계 | 내용 | 가치 |
|---|---|---|
| 1단계 가족 | 장소·동승자 쪽지, 쪽지 코스 (공모전 MVP) | 차량 특화 감성 경험 |
| 2단계 실용 | 쪽지 장소를 경유지로 추가(NaviHelper), 나에게 남기는 쪽지, Gleo AI 음성 명령 연동 | 일상적 사용, Retention |
| 3단계 오너 방명록 | 드라이브 명소·차박지에 오너들이 남기는 공개 음성 쪽지, 쪽지를 이은 드라이브 코스. AI 검수·신고 체계 | 현대차 오너 간 소속감, 커뮤니티 |
| 4단계 공식 쪽지 | 지자체·관광지·휴게소 제휴 쪽지, 쪽지 → 경유지 → 방문으로 이어지는 제휴 모델, 프리미엄 내레이션 코스, 다국어 관광 쪽지 | 수익 모델, 해외 확장 |
- 공개 쪽지 단계에서는 위치기반서비스사업 신고, 음성의 공개 동의, 광고 표시, 위험 구간(교차로·분기점) 쪽지 제한 등을 갖추어 운영합니다.
